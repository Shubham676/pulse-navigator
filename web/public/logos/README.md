# Platform logos

Put each platform's official logo here, named by its ID, as `.svg` (preferred), `.png` or `.webp`.
The Connections page picks it up automatically after the next deploy; without a file it shows a lettermark.

Use the logo files each company publishes in its brand or partner kit, and follow their usage rules.

IDs: amazon, flipkart, meesho, myntra, ajio, nykaa, firstcry, jiomart, tatacliq, snapdeal, blinkit, zepto, instamart, bigbasket,
shopify, woocommerce, bigcommerce, magento, wix, squarespace, dukaan, zohocommerce, ebay, etsy, walmart, noon,
shiprocket, delhivery, unicommerce, easyecom, webhook_in, webhook_out
